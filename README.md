# SVG Tutorial

## 📐 Coletânea de Exercícios para Aprender SVG

O repositório **SVG-Tutorial** é uma coletânea de exercícios e exemplos práticos destinados a facilitar o aprendizado e a compreensão de **SVG (Scalable Vector Graphics)** no contexto de desenvolvimento web, utilizando **HTML** e **CSS**. O projeto foca em demonstrar como criar, manipular e estilizar gráficos vetoriais diretamente no código, aproveitando as vantagens do SVG, como escalabilidade e leveza.

### ✨ Destaques do Projeto

*   **Foco em SVG:** O principal objetivo é a exploração das tags e atributos do SVG para a criação de formas, caminhos e gráficos.
*   **Aprendizado Prático:** A estrutura em pastas (`exercises`, `introduction`) sugere um formato de tutorial ou curso, onde cada seção aborda um aspecto diferente do SVG.
*   **Integração com CSS:** O projeto demonstra como o CSS pode ser usado para estilizar elementos SVG, controlando cores, traços e até mesmo animações.
*   **Tecnologias Web Padrão:** Utiliza HTML e CSS, as tecnologias base para a integração do SVG.

### 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso Principal |
| :--- | :--- |
| **SVG** | Criação de gráficos vetoriais escaláveis. |
| **HTML5** | Estrutura e incorporação dos elementos SVG. |
| **CSS3** | Estilização dos elementos SVG. |
| **PHP** | Presença de arquivos PHP, possivelmente para inclusão de partes de código (`renderPartial`) ou para servir os exemplos. |

### 📂 Estrutura do Projeto

O repositório é organizado para um fluxo de aprendizado:

```
SVG-Tutorial/
├── .idea/          # Arquivos de configuração do ambiente de desenvolvimento
├── exercises/      # Exercícios práticos de SVG
├── introduction/   # Arquivos de introdução e conceitos básicos
├── renderPartial/  # Possível uso de PHP para inclusão de partes de código
└── README.md       # Este arquivo
```

### 🚀 Como Visualizar

Para visualizar os exemplos, basta clonar o repositório e abrir os arquivos HTML dentro das pastas `exercises` ou `introduction` em seu navegador web:

```bash
# 1. Clone o repositório
git clone https://github.com/BrizidoAndre/SVG-Tutorial.git

# 2. Navegue até o diretório do projeto
cd SVG-Tutorial

# 3. Abra os arquivos HTML de exemplo no seu navegador
# (Exemplo para Linux/macOS)
open introduction/index.html
```
